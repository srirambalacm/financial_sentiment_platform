# Dependencies needed to run the test suite in CI.

# The test suite does not need them:
#
#   * src/sentiment.py imports torch and transformers lazily, inside the
#     function that loads the model, so the module imports fine without them
#     and the scoring maths is tested by injecting a label map.
#   * scikit-learn is only used by scripts/benchmark_model.py, which is a
#     batch job, not importable-under-test code.
#   * yfinance is only imported by src/ingest_prices.py, exercised through
#     the network in batch ingestion rather than in tests.
#
# The result is a CI install of a few seconds instead of several minutes.
# Use requirements.txt for a full local environment.
